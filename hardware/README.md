# Hardware Workspace

This directory records source-of-truth links, design notes, reviews, and release exports for the physical system.

- `cad/`: Onshape claw and fixture references.
- `pcb/base_controller/`: Phase 1 KiCad base-controller design.
- `fixtures/`: Safe calibration and bench-test fixtures.

Do not treat an exported CAD or fabrication file as the editable source unless its README says so.
