# Base Controller PCB Placeholder

Planned owner: Claw, PCB, and Robot-Side Mechatronics, with EMG/Haptics reviewing wearable-facing interfaces.

The Phase 1 board should consolidate low-voltage control and testable connectors for the selected controller, gripper actuator, force sensing, communications, and power. Exact MCU, connector, regulator, and protection choices remain design tasks.

Initial acceptance targets:

- reviewed block diagram and interface table;
- schematic passes electrical-rule checks;
- PCB passes design-rule checks;
- labeled power rails and test points;
- documented bench bring-up procedure; and
- no human-connected electrotactile output stage.
