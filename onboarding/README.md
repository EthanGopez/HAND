# Onboarding Reference Projects

These folders contain small, hardware-free exercises for the first workday.
They are intentionally separate from production code so members can learn one
concept at a time.

- `vha/`: ROS, simulated xArm, and camera hand tracking.
- `claw_pcb/`: Onshape, KiCad, and controller-firmware orientation.
- `emg/`: Offline EMG analysis, wearable firmware, and haptic simulation.
