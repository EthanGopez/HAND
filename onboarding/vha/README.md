# VHA Reference Projects

The prepared first-workday exercise is
[`hand_tracking_demo/`](hand_tracking_demo/README.md): members run MediaPipe
from a laptop webcam or prerecorded clip, inspect its landmark output, and
observe tracking loss. Ultraleap is not part of the project plan.

Ethan was here!!!!!

The custom ROS tutorial under `ros_demo/` is intentionally deferred. For the
first meeting, the project lead can demonstrate the existing xArm-6
MoveIt/Gazebo environment by following `ros_ws/README.md`. The repository also
keeps a lighter fake-hardware MoveIt/RViz launcher for laptops that struggle
with Gazebo. The later ROS exercise will cover topics, TF, bounded targets, and
the host-to-xArm TCP/IP boundary.
