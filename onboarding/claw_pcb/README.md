# Claw and PCB Reference Projects

The hardware-free first-workday path uses local design tools:

1. complete the guided KiCad schematic/board exercise and run rule checks; and
2. compile and inspect the controller firmware skeleton without uploading it.

These exercises teach the toolchain without requiring the claw, sensors, PCB, or microcontroller to have arrived.

The shared Onshape practice document is intentionally deferred until the
project lead creates it in the team workspace.
